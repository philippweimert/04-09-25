## Contributing Guidelines

### Getting Started
- Fork the repository and create a feature branch from `main`.
- Ensure you can run backend and frontend locally.

### Code Style
- Python: format with `black`, sort imports with `isort`, lint with `flake8`.
- JS/TS: use ESLint defaults included in the project.

### Testing
- Add or update tests for new features.
- Ensure `backend_test.py` and `contact_test.py` pass against your local backend.

### Commits
- Use clear, descriptive messages.
- Reference issues where applicable.

### Pull Requests
- Keep PRs focused and small.
- Include a brief description, screenshots if UI changes.
